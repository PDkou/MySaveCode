# 릴리스 기록

Play Console에 실제로 올린 각 버전이 정확히 어느 커밋 상태였는지 남겨두는 기록.
태그를 못 쓰는 환경이라 (git push로 새 태그를 못 올림) 여기 커밋 해시로 대신 기록함.

특정 버전의 코드 전체를 그대로 다시 보고 싶으면:

```
git checkout <커밋 해시>
```

또는 저장소를 건드리지 않고 파일 하나만 보고 싶으면:

```
git show <커밋 해시>:hellotoday-app/app/build.gradle.kts
```
