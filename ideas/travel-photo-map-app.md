# 아이디어: 여행 사진 지도 앱 (가칭)

> 상태: **아이디어 단계** — 아직 구현 시작 전. 착수 시점 판단을 위한 메모.
> 작성일: 2026-09-07

## 핵심 컨셉

사용자가 글을 쓰거나 동선을 잇는 스트레스 없이, **여행 사진만 업로드하면**
알아서 내 발자취를 지도에 박제해 주는 미니멀한 여행 기록 모바일 앱.

- **핵심 타겟**: "내가 정확히 언제 어디서 놀았었지?" 기억이 안 나서 답답한 여행자
- **기획의 미니멀리즘**: 복잡한 경로 연결(선 그리기)이나 일기(메모) 기능은 과감히 제외

## 주요 기능 구조 (MVP)

1. **사진만 던지는 업로드 (비용 0원)** — 사용자가 사진을 올리면 시스템이 사진 속
   EXIF 데이터(촬영 일시 + GPS 위경도 좌표)를 자동으로 추출.
2. **지도 위 썸네일 핀 박기** — 복잡한 경로 계산 없이, 추출한 좌표를 기반으로
   지도 위에 핀을 심는다. 일반 핀 대신 내가 찍은 사진의 작은 동그라미 썸네일을
   핀으로 활용해 시각적 소장 가치를 높인다.
3. **심플한 정보 제공** — 지도 위의 사진 핀을 터치하면 [사진 / 장소명 / 촬영 일시]
   딱 3가지 정보만 직관적으로 보여준다.

## 비용 절감 및 바이럴(공유) 전략

서버·지도 비용 걱정 없이 초기 비용 0원으로 구현하는 빌드업.

| 항목 | 구현 방식 | 비용 부담이 없는 이유 |
|---|---|---|
| 개발 방식 | FlutterFlow (노코드 툴) | 외주 개발비 없이 혼자 힘으로 빠르게 앱 출시 가능 |
| 지도 API | 구글 맵스 | 모바일 앱에 지도를 띄우는 것은 완전 무료 |
| 서버 & DB | 구글 Firebase | 유저 수천 명 규모(사진 저장 5GB)까지 평생 무료 구간 제공 |
| 바이럴 웹 | 웹 URL 배포 기능 활용 | 공유 시 상대방은 앱 설치 없이 브라우저에서 지도 조회 가능 |

**바이럴 치트키**: 친구의 공유 링크를 타고 들어왔을 때, 지도 하단에
`[나도 내 사진으로 여행 지도 만들기]` 버튼을 노출해 자연스러운 신규 유저 유입을 유도.

## 다음 단계 후보 (착수 시 선택)

아이디어 다듬는 과정까지는 끝난 상태. 실제로 착수하게 되면 아래 중 하나부터:

- [ ] FlutterFlow / Firebase 가입 및 프로젝트 셋업 가이드
- [ ] EXIF 파싱·GPS 좌표 추출 로직 프로토타입 (노코드 툴 밖에서 먼저 검증)

## 리스크/미결정 사항 (착수 전 짚어볼 것)

- EXIF에 GPS가 없는 사진(캡처본, 메신저로 전달받은 사진 등) 비율이 높을 수 있음 —
  이 경우 핀을 못 찍는 사진이 상당수 생길 수 있어 UX 처리 방안 필요.
- iOS는 사진 공유 과정에서 EXIF GPS가 종종 제거됨(카톡 전송 등) — "직접 촬영한
  원본"만 대상으로 한정할지 여부 결정 필요.
- Firebase 무료 티어(Spark) 저장 용량/대역폭 한도를 실제 사용량 추정치와
  대조해 볼 것.
