# Hungry Pack — 무드보드 (총괄아트, 오리지널 제안)

로고(Howling 스튜디오 브랜드)와는 별개로, 게임 자체 컨셉만 기준으로 처음부터 설계했습니다. 참고한 특정 레퍼런스 없음.

## 핵심 감정
- **춥고 조용한 긴장감** — 사냥 중엔 차갑고 날카로운 느낌
- **집(무리)의 온기** — 귀환했을 때만 느껴지는 따뜻함, "안전"의 보상감
- 이 둘의 대비가 "계속할까 귀환할까" 선택의 감정적 무게를 시각적으로 뒷받침해야 함

## 컬러 스크립트
| 용도 | 색 | 의도 |
|---|---|---|
| 배경(사냥 중) | 짙은 겨울밤 남색 `#0F1724` | 눈 덮인 밤, 차갑고 고요함 |
| 기본 텍스트 | 서리 낀 화이트 `#EBF2F7` | 눈빛처럼 차갑지만 선명하게 |
| 정보/스탯 강조 | 얼음빛 페일 블루 `#8CBFE0` | 냉정한 판단이 필요한 수치들 |
| 성공/귀환 | 온기 앰버 `#EDAD3F` | 모닥불, 집으로 돌아왔을 때의 따뜻함 |
| 함정/위험 | 녹슨 적색 `#BF4033` | 피, 위험, 차가움 속의 경고 |

일반 다크 UI 톤(그레이/블랙 계열)이 아니라 **"밤+눈"이라는 구체적 장소성**을 컬러에 담은 게 의도입니다. 로고의 무채색(블랙/화이트)과는 분리된, 게임 고유의 색 정체성입니다.

## 형태 언어 (추후 실제 아트 제작 시 적용)
- 위험 요소(함정, 겨울 심화)는 **날카롭고 각진 실루엣**
- 안전/보상 요소(귀환, 유물)는 **둥글고 부드러운 실루엣**
- 플레이어가 굳이 설명 안 들어도 "이건 위험, 이건 안전"을 형태만으로 직관적으로 구분하게 하는 게 목표

## 적용 현황
- `scripts/GamePalette.gd`로 위 컬러 스크립트를 코드에 반영, `Main.gd`(실제 플레이 화면)에 적용
- 인트로 화면(`Intro.gd`)은 게임 무드보드가 아니라 **스튜디오 브랜드 컬러(`Palette.gd`, 로고의 블랙/화이트)** 를 그대로 유지 — 스튜디오 워터마크와 게임 자체 아트는 의도적으로 분리
- 형태 언어(각진 위험 vs 둥근 안전)는 아직 전부 사각형뿐이라 미적용 — Day 3 실제 아트 패스에서 반영 예정
