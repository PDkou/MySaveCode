# Lane Rush (가제) — 게임 기획서

## 개요
- **장르**: 하이스코어 아케이드 (원버튼 레인 전환 낙하 회피)
- **엔진**: Godot 4.7
- **목표 플랫폼**: PC (스팀), 추후 모바일 이식 고려
- **개발 기간**: 1주 — 오프라인 코어 루프 완성 우선, 온라인/스팀 출시는 다음 단계

## 코어 루프
1. 플레이어는 화면 하단, 3개 레인 중 하나에 위치
2. 좌/우 탭(또는 방향키)으로 인접 레인으로 즉시 전환
3. 위에서 장애물과 코인이 각 레인으로 낙하 (매 웨이브 최소 1개 레인은 항상 비어 있어 항상 회피 가능)
4. 장애물 충돌 시 게임 오버, 코인 획득 시 점수 +10
5. 시간이 지날수록 낙하 속도 증가 (난이도 커브)
6. 게임 오버 → 점수/최고 점수 표시 → 즉시 재도전 버튼 (재시작 마찰 최소화가 중독성의 핵심)

## 이번 주 스코프
- 오프라인 로컬 플레이만 (온라인 리더보드는 다음 단계)
- 로컬 최고 점수 저장 (user:// 세이브 파일)
- 미니멀 지오메트릭 아트 (컬러 사각형/원, 스프라이트 아님 — 아트 리소스 제작 시간 절약)

## 로드맵 (총괄디렉터 초안, 조정 가능)
| Day | 목표 |
|---|---|
| 1 | 기획 확정 + 프로젝트 셋업 + 코어 루프(이동/장애물/코인/충돌/점수) — **완료** |
| 2 | 난이도 커브 튜닝, 회피 불가 상황 방지 로직 검증 |
| 3 | 아트 패스 (미니멀 지오메트릭 스타일 확정, 배경/파티클) |
| 4 | 사운드/이펙트 (스크린셰이크, 히트/코인 SFX) |
| 5 | UI/메뉴 다듬기, 콤보/멀티플라이어 등 스킬 요소 검토 |
| 6 | 버그픽스 + 플레이테스트 |
| 7 | 폴리싱 + 다음 단계(온라인 리더보드/스팀 출시 준비) 계획 수립 |
