# 꾸며진 스토어 스크린샷/피처 그래픽

폰 프레임 목업 + 배경 일러스트 + 로고/태그라인으로 꾸민 버전. 자사
다른 앱 "Drawary"(나만의 서랍장)의 스토어 에셋 스타일을 참고해서,
director가 외부 이미지 생성 도구(GPT)로 제작.

- `feature-graphic-1024x500-{ko,ja}.png`: 1024x500px (Play Console
  요구 규격에 맞춰 리사이즈 완료)
- `screenshots-{ko,ja}/`: 01_reveal_legendary ~ 05_detail_legendary,
  실제 앱 화면이 폰 프레임 안에 정확히 들어간 상태

상위 폴더의 `../feature-graphic-1024x500-{ko,ja}.png`,
`../screenshots/`, `../screenshots-ja/`는 꾸미지 않은 순수 앱 화면
캡처본(참고/디버그용)으로 별도 유지.
