# PRODUCT_SPEC — 또 열었네? / また開いた？

## 1. 제품 한 줄 설명
스마트폰 사용 패턴을 사용자가 직접 입력하지 않아도 자동 분석하고, 반복·방황·심야 사용 같은 행동을 **탐정 고양이 모니가 “사건 카드”로 기록**해주는 엔터테인먼트형 습관 앱.

## 2. 제품 목표
- 생산성 앱처럼 훈계하지 않는다.
- 사용자가 매번 데이터를 입력하지 않아도 된다.
- 단순 통계보다 “오늘 무슨 사건이 있었나”를 보게 만든다.
- 수집/등급/히든 요소로 앱을 다시 열 이유를 만든다.
- 카드 공유가 밈 이미지처럼 퍼질 수 있게 한다.

## 3. 핵심 사용자 흐름
1. 최초 실행 → Usage Access 권한 설명/설정 이동.
2. 홈 → 오늘의 사건 및 대표 카드 표시.
3. 카드 상세 → 사건 내용, 발생 시각, 지표, 관련 사건 확인.
4. 보관함 → 발견한 사건/등급을 수집 상태로 확인.
5. 기록 → 하루 사용 요약과 과거 사건을 확인.
6. 공유 → 정사각형 또는 스토리형 공유 카드 생성.

## 4. 카드 등급
- NORMAL
- RARE
- EPIC
- LEGENDARY
- HIDDEN

HIDDEN은 일반 등급과 별도 수집 대상으로 취급하며, 현재 엔진에는 두 종류의 숨김 사건이 존재한다.

## 5. 현재 사건 카탈로그
- QUICK_EXIT — 짧게 열고 닫기를 반복
- REENTRY — 같은 앱을 짧은 간격으로 재진입
- REGULAR — 특정 앱을 매우 자주 방문
- RETURN_TO_START — 여러 앱을 돌고 최초 앱으로 복귀
- PATROL — 짧은 시간에 여러 앱을 순찰
- ESCAPE_FAILED — 짧은 시간에 같은 앱을 반복 재오픈
- FIRST_CONTACT — 잠금 해제 후 가장 먼저 연 앱
- NIGHT_PATROL — 심야 다중 앱 사용
- APP_WANDERING — 앱 전환이 많고 체류가 짧은 방황 패턴
- HUNDRED_VISITS — 특정 앱의 매우 높은 방문 횟수
- DIGITAL_LOST — 복잡한 앱 왕복/다중 전환
- DAWN_SURVIVOR — 새벽 장시간 사용
- HIDDEN_LOOP — 두 앱만 빠르게 번갈아 사용하는 히든 패턴
- HIDDEN_NIGHT_ACTIVITY — 새벽에 짧은 잠금해제 세션을 여러 번 반복하는 히든 패턴

## 6. 제품 톤
- “감시”보다는 “관찰/사건 기록”
- “중독” 같은 공격적 진단은 피하고 유머러스하게 표현
- KR/JP 모두 자연스러운 현지 문구 사용
- 사용자의 사용 습관을 비난하지 않고 웃을 수 있게 보여준다.
