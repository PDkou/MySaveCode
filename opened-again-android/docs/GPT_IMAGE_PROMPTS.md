# GPT_IMAGE_PROMPTS

`docs/ASSET_REQUESTS_FOR_DESIGN.md` 6번 요청(사건 일러스트 12종 × 4등급 +
HIDDEN 2종 = 50장)을 실제로 만들 "디자인팀"이 사람이 아니라 GPT 이미지
생성이라는 걸 알게 돼서, 스펙 문서 대신 **바로 복붙해서 넣을 수 있는 프롬프트
50개**를 여기 준비함.

## v2 개정 (실제 생성 결과 피드백 반영)

QUICK_EXIT LEGENDARY 첫 생성 결과가 "5초컷" 장면이 아니라 성/깃발/월계관이
등장하는 "전쟁 승리/정복 영웅" 그림으로 나왔음 — LEGENDARY 등급 지시문이
"epic celebratory mood", "heroically" 같은 추상적인 화려함 지시만 하다 보니
GPT가 알아서 무관한 배경 요소(성/깃발/왕실 이미지)를 끌어다 붙인 것.
아래처럼 전면 수정함:
- 모든 프롬프트 하단 기술 스펙에 **"등급과 무관하게 원래 장면/설정을 그대로
  유지할 것"**을 명시하는 문장을 추가
- EPIC/LEGENDARY 등급 지시문에 **"위에 설명된 설정·소품·행동을 그대로 유지하고,
  장면에 명시되지 않은 성/타워/깃발/문장(紋章)/왕관/월계관/왕좌/퍼레이드나
  중세·왕실·전쟁 이미지를 새로 추가하지 말 것"**을 명시적으로 지시
  (단, HUNDRED_VISITS처럼 장면 설명 자체에 왕관이 이미 포함된 경우는 예외)
- 각 타입의 LEGENDARY 장면 문구에서 "heroically"(영웅적으로) 같이 판타지 영웅
  서사를 연상시키는 단어를 "dramatically"(극적으로)로 순화, "trophy"(트로피)
  같이 시상식/정복 이미지를 유발할 수 있는 단어도 순화
- 화려함은 색감/조명/반짝임 효과/포즈 에너지로만 표현하고, 장면 자체(설정·소품)는
  4등급 내내 동일하게 유지하도록 강제

## 사용 방법
0. **채팅(대화형) 모드로 쓸 것, 별도 "이미지 생성" 전용 탭 말고.** 이유:
   (a) 레퍼런스 이미지 첨부가 채팅 모드에서만 제대로 됨 — 전용 탭은 첨부가
   안 되거나 제한적인 경우가 많음. (b) 결과가 마음에 안 들 때 "모자 색 바꿔줘"
   처럼 같은 대화에서 바로 이어서 수정 요청 가능. (c) 같은 타입의 4등급을
   한 대화 안에서 순서대로(NORMAL→RARE→EPIC→LEGENDARY) 생성하면 "방금
   그림에서 이만큼 더 화려하게"로 자연스럽게 이어져서 톤 일관성이 더 잘
   유지됨. 타입이 바뀌면 새 대화로 넘어가되, 레퍼런스 이미지는 매번 다시
   첨부해야 함(이전 대화 기억은 새 창에 안 넘어감).
1. 매번 새 대화(또는 이미지 생성 요청)에 **캐릭터 참고 이미지 한 장을 같이
   첨부**할 것 — `app/src/main/assets/visual/character/basic/moni_phone.png`
   추천(캐릭터 디자인이 가장 표준적으로 나온 파일). 참고 이미지 없이 텍스트만
   주면 매번 캐릭터 얼굴/비율이 미묘하게 달라져서 "AI틱하다"는 지적이 반복될
   가능성이 높음 — 이번 재작업의 핵심 이유가 그거였으니 특히 중요.
2. 아래 프롬프트를 그대로 복사해서 붙여넣기 — 이미 캐릭터 스타일 고정 문구 +
   장면 설명 + 등급별 화려함 지시(장면 유지 제약 포함) + 기술 스펙까지 다
   포함되어 있어서 따로 손볼 필요 없음.
3. 결과가 원래 사건 장면에서 벗어나 있으면(예: 엉뚱한 배경/소품이 추가됨)
   "같은 장면 그대로 유지하고 [문제된 부분]만 빼줘" 식으로 바로 수정 요청.
   같은 프롬프트로 재생성해도 대개 비슷한 결과가 나옴.
4. 파일을 받으면 정해진 이름으로 저장:
   `incident_<타입 슬러그>_<등급>.png` (예: `incident_quick_exit_legendary.png`).
   HIDDEN 2종은 등급 접미사 없이 `incident_hidden_loop.png`,
   `incident_hidden_night_activity.png`로 저장(기존 파일 덮어쓰기).
5. 파일이 하나씩 나올 때마다 나(클로드)한테 주면 바로 반영함 — 50장 다 모을
   때까지 기다릴 필요 없음. 우선순위 추천: LEGENDARY 12장(가장 눈에 띔) →
   자주 뜨는 타입(5초컷/재입장 사건 등) → 나머지 순서로 해도 됨.
