# CARD_LAYOUT_SPEC

공유 카드(트레이딩카드 스타일) 좌표의 **단일 진실 공급원(single source of
truth)**. 목업 파이썬 코드, Card Layout Bench 툴, 실제 `ShareCardRenderer.kt`
전부 이 스펙 하나만 보고 그려야 함 — 프레임 이미지를 새로 뽑거나 등급을
바꿔도 이 숫자는 **절대 다시 재지 않음**.

## 원칙

1. **좌표는 이 문서에만 있다.** 프레임 PNG를 열어서 "여기가 헤더판인가?"
   측정하는 코드는 없어야 함. 프레임은 그냥 배경 그림이고, 그 위에 항상
   같은 자리에 얹는다.
2. **5등급이 전부 같은 숫자를 쓴다.** 색상·장식·엠블럼 그림만 등급별로
   다르고, 위치·크기는 절대 등급별로 분기하지 않는다 (메달 표시 크기
   보정 `medal_fix`만 예외 — 이유는 아래 참고).
3. **기준 캔버스는 1024×1536.** 다른 크기(예: 실제 앱의 1080×1080,
   1080×1920)로 낼 때는 전체를 하나의 배율로 통일 스케일링만 하고,
   요소별로 따로 계산하지 않는다.
4. **프레임 배경은 `object-fit: cover`(또는 stretch)로 캔버스에 맞춘다.**
   프레임 자체의 원본 비율이 1024×1536과 정확히 안 맞아도 늘려서 채운다
   — 안쪽 내용물 위치에 전혀 영향 없음.

## 좌표 (1024×1536 기준, 단위 px)

**v16 최종본.** 아트창 높이는 v13 초안(765)에서 두 차례 더 줄어
935으로 확정됐다 — 감독 피드백("일러스트가 좀 크니까 살짝만 줄여서")
반영, 소스 일러스트의 16:9 원본 비율에 더 가까워져서 cover 크롭도
덜 공격적으로 됨 (박스는 작아졌는데 더 넓게 보이는 두 마리 토끼).

| 요소 | X | Y | 폭 | 높이 | 비고 |
|---|---|---|---|---|---|
| 헤더 패널 | 97 | 200 | 828 | 109 | 반투명 흰/다크 사각형, 라운드 22 |
| 등급 칩(pill) | 헤더 X+26 | 헤더 Y+15 | 텍스트폭+20 | 26 | 라운드 13, 5등급 전부 색칠된 pill (HIDDEN만 그라디언트+반짝이 2개) |
| 제목 텍스트 | 헤더 X+26 | 헤더 Y+46 | - | - | EPIC 이상은 foil 처리 (아래 참고) |

## FX 레벨 (등급별 반짝임/글로우 escalation)

감독: "에픽이상은 fx효과도 좀 넣어줘". `fx` 값 0/1/2 — HIDDEN은 이
스케일 대신 자기만의 "신비로운" 처리(아래 참고)를 받는다.

| 등급 | fx | 엠블럼 글로우 | 엠블럼 반짝이(별) |
|---|---|---|---|
| NORMAL | 0 | 없음 | 없음 |
| RARE | 0 | 없음 | 없음 |
| EPIC | 1 | 반경 0.85×지름, blur 22, opacity 140 | 6개, 반지름 5~9 |
| LEGENDARY | 2 | 반경 0.85×+1.3×지름 이중, blur 22/40, opacity 140/90 | 9개, 반지름 6~12 |
| HIDDEN | - | 코어 글로우 반경 1.15×지름 (색 30,120,150), blur 34, opacity 110 | 없음 (대신 이중 링 + 궤도 점 10개) |

**드로우 순서 주의**: 엠블럼 글로우는 반드시 헤더 패널보다 **먼저**
그린다 — 글로우의 블러 반경이 헤더 패널 y범위까지 침범하는데, 패널보다
나중에 그리면 패널 위에 흐릿한 얼룩이 겹쳐 보이는 버그가 있었다 (패널을
먼저 그려야 그 불투명한 채움이 침범분을 가려준다).

## 등급 칩(rarity label pill)

감독: "노멀도 레어도 [칩] 해줘" (전 등급에 pill), HIDDEN은 "가장
얻기 힘든거니까 좀 더 화려하게":

- NORMAL/RARE/EPIC/LEGENDARY: `pal.glow` 색으로 단색 채움 pill.
- HIDDEN: 가로 그라디언트 채움 `(70,190,210)→(225,252,255)→(90,210,225)`
  + 밝은 테두리 `(235,255,255)` + 좌우로 작은 8각 반짝이 별 2개.
- 칩 안쪽 텍스트 색은 등급별 대비 확보용 별도 지정 (하양/짙은색 등,
  `CardStyle.tcgPalette().chipTextColor` 참고).

## 제목 foil 처리 (EPIC 이상)

감독: "에픽이상은 카드 이름도 fx효과랑 색깔 효과도 넣어줘, 포켓몬카드나
유희왕카드 참고해서" → 이후 "히든은 아예 무지개색으로".

글로우(블러) → 두꺼운 아웃라인 스트로크 → 그라디언트 채움, 3단 레이어.
NORMAL/RARE는 이 처리 없이 그냥 `pal.text` 단색.

| 등급 | 그라디언트 방향 | 색상 | 이유 |
|---|---|---|---|
| EPIC | 세로(위→아래) | 보라 2단 | 가로 그라디언트는 글자 위치에 따라 밝기가 달라져서, EPIC/LEGENDARY처럼 밝은 헤더 패널 위에서 일부 글자가 거의 안 보이는 문제가 있었음 (director 피드백으로 발견) — 세로는 모든 글자가 동일하게 음영져서 대비가 균일함 |
| LEGENDARY | 세로(위→아래) | 금색 2단 | 위와 동일 이유 |
| HIDDEN | 가로(좌→우), 7색 무지개 | 빨-주-노-초-파-남-보 | HIDDEN 패널이 어두운 남색이라, 무지개의 어떤 색이 와도 배경과 확실히 대비됨 — 가로 방향이라도 안전 |

구현 위치: `CardStyle.foilTitle(rarity)` (색상/아웃라인/글로우 색 +
`vertical` 방향 플래그), 실제 드로잉은 `ShareCardRenderer.drawFoilText()`
— glow(블러 페인트) → stroke 아웃라인 → `Paint.shader = LinearGradient`
채움, Android의 `drawText`는 항상 글리프 모양에만 칠하므로 별도 마스크
불필요 (PIL 목업은 명시적 alpha 마스크가 필요했음).

## 예외: `medal_fix` (등급별 메달 표시 배율)

엠블럼 위치·크기는 통일이지만, 메달 셸 PNG 자체가 등급마다 "링이 캔버스를
채우는 비율"이 달라서(EPIC/LEGENDARY의 반짝임 장식이 캔버스 가장자리에
더 가깝게 그려짐) 같은 162px로 그리면 링이 작아 보임. 이건 좌표 문제가
아니라 **소스 이미지 자체의 여백 차이**라서, 배율 하나로 보정:

| 등급 | medal_fix |
|---|---|
| NORMAL | 1.00 |
| RARE | 1.00 |
| EPIC | 1.12 |
| LEGENDARY | 1.22 |
| HIDDEN | 1.00 |

메달 이미지를 `162 * medal_fix` px로 그리고, 항상 엠블럼 중심(508,125)에
가운데 정렬. 새 메달 에셋을 받으면 이 배율도 다시 확인.

## HIDDEN 엠블럼 전용 처리

RARITY_SYMBOL이 없는 유일한 등급 — 아이콘 대신: 코어 글로우(위 FX 표) +
이중 원형 링(안쪽 실선, 바깥쪽 반투명) + 궤도를 도는 작은 점 10개 +
글로우 처리된 "?" 글리프. "히든 앰블렘이랑 타이틀은 좀 더 히든스럽게"
피드백으로 확정 — EPIC/LEGENDARY의 "축하" 느낌 반짝이 별과는 다르게
"조용한 비밀"에 가까운 톤으로 의도적으로 다르게 처리.

## 구현 위치

- 파이썬 목업: `sim_tcg_v16.py`의 `GEOMETRY`/`PALETTE`/`FOIL_TITLE` dict
  (최종 확정본 — 이 문서와 1:1 대응)
- 브라우저 도구: Card Layout Bench의 `DEFAULTS` (초기 좌표 스냅샷용,
  v16 폴리시 라운드 이후로는 갱신되지 않음 — 좌표 기준은 이 문서가 우선)
- 실제 앱: `ShareCardRenderer.kt`의 `private object CardLayout`에 좌표
  상수로, `CardStyle.kt`에 색/foil 데이터로 이식 완료. `Format.SQUARE`/
  `STORY`마다 `scale = rect.width() / CardLayout.W` 단일 배율로
  스케일링 — 요소별 좌표를 포맷마다 따로 계산하지 않음.

이 문서의 좌표가 바뀌면 **파이썬 목업 → 이 문서 → `ShareCardRenderer.kt`/
`CardStyle.kt`** 순서로 반영.
