# LOCALIZATION_SPEC

## 지원 언어
- 한국어
- 일본어
- 영어

## 원칙
- 코드/아이콘과 텍스트 라벨 분리.
- UI 아이콘에 특정 언어 글자를 구워 넣지 않는다.
- WebView의 문자열과 Android `strings.xml`의 역할을 구분해 관리한다.
- 사건 제목/펀치라인은 단순 직역보다 각 언어에서 자연스러운 유머 톤을 우선한다.

## 기본 네비게이션 용어
| Key | KR | JP | EN |
|---|---|---|---|
| home | 홈 | ホーム | Home |
| records | 기록 | 記録 | Records |
| collection | 보관함 | コレクション | Collection |
| settings | 설정 | 設定 | Settings |
| share | 공유 | シェア | Share |
| back | 뒤로 | 戻る | Back |
| close | 닫기 | 閉じる | Close |
| language | 언어 | 言語 | Language |
| notification | 알림 | 通知 | Notifications |
| filter | 필터 | フィルター | Filter |

## 제품명
- KR: 또 열었네?
- JP: また開いた？
- EN은 현재 UI/로고 테스트에서 `Opened Again`이 사용됨.

## 톤 예시
KR: “오늘도 또 열었네?” / “내 폰이 오늘도 보고 있었다.”
JP: “また開いた？” / “スマホは今日も見ていました。”

최종 스토어 문구와 사건명 번역은 출시 전 별도 언어 QA가 필요하다.
