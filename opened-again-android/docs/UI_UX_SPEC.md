# UI_UX_SPEC

## 1. 전체 분위기
- 크림/아이보리 기반의 귀여운 탐정 세계관.
- 일반 생산성 대시보드처럼 딱딱하게 보이지 않게 한다.
- 홈/보관함/기록 모두 “모니가 오늘의 사건을 정리해주는 앱”처럼 느껴져야 한다.

## 2. 주요 화면
### Splash
- 브랜드명과 모니 중심.
- 짧고 가벼운 진입.

### Onboarding / Usage Access
- “사용 기록을 확인하려면 권한이 필요해요” 식으로 설명.
- 시스템 Usage Access 설정으로 이동.
- 계정/서버 없이 기기 내 분석 중심.

### Home
- 오늘의 대표 문구.
- 오늘의 사건 카드 1개를 크게 노출.
- 추가 사건 목록은 등급 칩과 함께 표시.
- 하단 탭: 홈 / 기록 / 보관함 / 설정.

### Card Detail
- 등급
- 사건명
- 발생 시각
- 사건 일러스트 영역
- 사건 설명
- 지표(횟수/평균 시간/시간대 등)
- 공유 버튼

### Collection / 보관함
- 발견한 사건을 카드 그리드로 수집.
- 미발견 HIDDEN은 `???` 잠금 상태.
- 단순 “파일 목록”이 아니라 사건 도감 느낌.

### Records
- 날짜별 사건 기록.
- 사용시간/오픈수/전환수/상위 앱 등 통계는 보조 정보.
- 통계 앱처럼 숫자만 보이지 않게 모니의 “수사 보고서” 톤 유지.

### Settings
- Usage Access 상태
- 공유/백업 관련 설정
- 언어
- 데이터 관리

## 3. 등급 표현
- NORMAL — 최소 장식
- RARE — 하늘색 계열 강조
- EPIC — 보라 계열
- LEGENDARY — 금색/강한 광원
- HIDDEN 01 — 심야 네이비/미스터리
- HIDDEN 02 — 오팔/몽환 계열

등급이 올라갈수록 프레임/효과가 강해져야 하지만, 본문 가독성을 해치지 않는다.

## 4. 공유 카드
- 소셜에서 한눈에 읽히는 제목을 크게.
- 사건명 + 짧은 펀치라인 + 모니 + 핵심 숫자.
- SQUARE와 STORY 포맷 대응.
- 사용자가 “통계표”가 아니라 “오늘의 밈 카드”처럼 공유하도록 설계.

## 5. 현지화 UI 원칙
- 아이콘은 무라벨 공용 아이콘을 사용.
- 텍스트는 KR/JP/EN 리소스에서 분리 렌더링.
- 일본어 라벨이 박힌 이미지는 참조용으로만 보관하고 실제 빌드에는 사용하지 않는다.
