# V2-12 step 1-A addendum: bundled font (Noto Sans KR)

**Why.** Approved screens list `'Noto Sans CJK KR'` first (a few list NanumSquare/Arial/Inter, no single font was recorded) but the app shipped no font file, so every screen drew with whatever the device or sandbox had. The user confirmed the intended font is Noto Sans CJK KR. `DESIGN_APPROVAL_LOCK.md` had deferred "global font harmonization"; this is that pass for the Korean face.

**What.** `public/fonts/noto-sans-kr/` holds Noto Sans KR (SIL OFL 1.1, `LICENSE.txt`) as woff2 slices (121 files, 3.8 MB; cyrillic/vietnamese/latin-ext left out), loaded from `index.html` by `fonts.css`. It is registered under the names the screens already use (`Noto Sans CJK KR`, `Noto Sans KR`), so **no screen CSS changed for this**.

**Weights.** Only 400 and 700 are declared, so any requested weight snaps to the nearer one (<=500 -> 400, >=600 -> 700), like installed static fonts. Choice was measured, not assumed: 10 screens with approved references (mean abs pixel diff, summed) -- variable 35.33, 400+700 **34.79**, 400/500/700 34.85, 300/400/500/700 34.85, 300/400/500/700/900 35.70. Differences are small; the user also preferred the 400+700 render by eye on #38.

**Effect on parity (diff vs approved render, before -> after the font):** #12 2.33 -> 0.39, #13 2.32 -> 0.64, #9 3.26 -> 1.38, #20 4.24 -> 1.81. Not better: #38 settings 3.16 -> 4.54, #25 6.49 -> 7.20, #29 2.98 -> 3.20, #33 3.21 -> 3.59 (their layouts already differ from the references by a few px, so glyph shifts show up). Not investigated further.

**Not covered.** Japanese (needs Noto Sans JP when i18n is built); `NanumSquare` screens fall back to Noto as before; the Android shell must serve `/fonts/` from its bundled assets (check at Android QA); app size grows by ~3.8 MB.

**Also fixed.** `.hs-edit` / `.hs-done` lost their font size to the `.hs-screen button{font:inherit}` reset; raised specificity. Home text weights/sizes re-tuned against the approved #3 render with the real font (all text boxes within 1-2px).
