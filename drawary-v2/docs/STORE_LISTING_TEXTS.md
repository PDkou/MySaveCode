## English (Drawary) — 기본 언어

Short description:
```
Keep what you love in drawers you set up yourself. No account, no ads.
```

Full description:
```
Books, skincare, movies, plants, trips you've taken, this month's budget. There's a lot you'd like to keep track of, and a single notes app turns into a mess fast.

Drawary lets you sort all of that into drawers. Make a drawer, then add only the fields you need: text, date, price, rating, photos, links, check boxes or choices. If you're not sure what to make, pick one of 9 templates and start from there.

Everything you save can be searched across all your drawers at once, or laid out as a table you can sort and filter. Add a date field and Drawary will remind you on that day. Records that repeat every month can be created for you automatically.

The flip side is that losing your phone can mean losing your records, so make a backup file once in a while. You can use the same file to move to a new phone. There's also an app lock (PIN, fingerprint or face).

Up to 5 drawers and the default theme are free. If you want more, there's a one-time purchase, not a subscription, that unlocks more drawers, the other themes, repeating records and CSV and PDF export.

Available in English, Japanese and Korean.

Contact: db5704@gmail.com
```
