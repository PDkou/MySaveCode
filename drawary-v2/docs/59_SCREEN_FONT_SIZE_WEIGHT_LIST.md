## Detail and caveats

- Full CSS values by component: [A](TYPOGRAPHY_A.md), [B](TYPOGRAPHY_B.md), [C](TYPOGRAPHY_C.md).
- This is a declaration-level inventory; the actual computed size or weight of a particular string depends on matching selector and inheritance.
- Font family is globally enforced via `src/styles.css` with `!important`. This changes no font-size or font-weight values.
- Runtime glyph parity requires that the `Noto Sans CJK KR` font actually be available on the target system; otherwise sans-serif is used.
