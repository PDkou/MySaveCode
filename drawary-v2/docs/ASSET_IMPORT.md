# Approved design-asset import

Asset sources are from approved Drawary design deliveries and should be copied without visual retouching.

1. Collect final approved HTML/CSS and PNG render per screen (59 screens).
2. For reusable WebP/PNG assets, use original file bytes when available. Do not extract from screenshots if an original exists.
3. Restore asset paths under `public/assets/` (or import assets via `src/assets/`) and verify transparency/legibility.
4. Source candidates exist in the prior user-approved delivery ZIPs (not automatically uploaded to this GitHub folder).
5. Keep an `asset-manifest` recording filename, origin, SHA-256, and screens that use it.
6. Preserve the original Google Drive logo where licensing and source are appropriate; do not replace with a hand-drawn lookalike.
7. Avoid emojis where the original fixed WebP asset exists.

Important: V2's initial GitHub scaffold does **not** yet include the full approved asset inventory or 59 integrated screens. Never represent placeholders as finished app screens.
