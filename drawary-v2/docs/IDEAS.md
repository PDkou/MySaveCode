# 아이디어 목록

앱은 계속 업데이트하는 거라서, 나온 아이디어를 여기에 모아 둬요. 새 아이디어가 나올 때마다 덧붙여요.

- 우선순위는 지금 기준의 생각이에요. 폰에서 쓰면서 나온 불편이 생기면 그게 먼저예요.
- 버전은 중간 숫자가 새 기능이에요 (`CLAUDE.md`의 버전 규칙).
- 이 앱의 약속: 로그인 없음, 서버 없음, 기록은 내 폰에만. 아래 아이디어는 가능하면 이 약속 안에서 해요.

## 사용자 아이디어

| 아이디어 | 메모 | 우선순위 |
|---|---|---|
| 서랍을 SQL 파일(`CREATE TABLE` + `INSERT`)이나 SQLite 파일로 내보내기 | 서랍 하나가 표 하나, 서랍 칸이 열, 보관품이 행이라 구조가 잘 맞아요. 내보낸 파일을 사용자가 직접 DB에 올리게 해요 | 1.0.0 이후, 프리미엄 후보 |
| 내보낸 데이터를 바로 업로드 | 앱이 서버와 직접 통신하면 "서버 없음" 약속과 개인정보 안내가 달라져요. 파일만 만들고 올리는 건 사용자가 하게 하는 쪽이 안전해요 | 보류 (약속과 충돌) |

## Claude 제안

### 데이터 넣고 빼기
| 아이디어 | 메모 | 우선순위 |
|---|---|---|
| CSV 가져오기 | 엑셀, 노션에서 쓰던 표를 서랍으로 가져와요. 서랍 칸 종류는 열 내용을 보고 추천해요. 처음 쓰는 사람이 시작하기 쉬워져요 | 높음 |
| JSON 내보내기 | 다른 도구와 연결하기 좋아요. 앱 백업과는 별개의 읽기 쉬운 파일이에요 | 중간 |
| 서랍 하나만 백업, 복원 | 지금 백업은 앱 전체예요. 서랍 하나만 내보내서 다른 폰이나 다른 사람에게 줄 수 있어요 | 중간 |
| 서랍 구성 공유(템플릿 파일) | 서랍 칸 구성만 담은 파일을 주고받아요. 기록은 들어가지 않아요 | 낮음 |

| 아이디어 | 메모 | 우선순위 |
|---|---|---|

| 앱 아이콘 길게 눌러 바로 담기 | 안드로이드 바로가기로 "새 보관품 담기"를 열어요 | 중간 |

| 표 보기에서 열 숨기기, 순서 바꾸기 | 칸이 많은 서랍에서 필요한 열만 봐요 | 중간 |
| 서랍 복제 | 비슷한 서랍을 칸 구성 그대로 새로 만들어요 | 중간 |
