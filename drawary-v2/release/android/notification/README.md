# Android notification (status bar) icon

White flower, transparent background, anti-aliased. Drawn from geometry (five round petals + centre hole, fitted to the
shape of the supplied master, 96% overlap) instead of tracing the supplied pixels, so the edges are smooth at every size.
`drawable-*/ic_stat_drawary.png` go into the Android project's `res/` (24/36/48/72/96 px). Status: made by Claude on
2026-10-20 as the user asked ("매끄럽게 너가 만들어서 쓰면 됨"). Replaces the old icon with corner arcs in `public/assets/android/notification`.
