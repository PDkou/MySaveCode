# 칭호 티어 매핑

`gamification-iconography.md`에서 만든 브론즈/실버/골드/플래티넘/다이아/마스터 6단계 프레임을 76개
칭호 각각에 연결하기 위해 작성한 매핑입니다.

**✅ 2026-07-31에 스키마/코드에 반영 완료** — `shop_items.tier` 컬럼(schema.sql 섹션 27)에 아래
표 그대로 채워 넣었고, `TitleFrame.tsx`/`.title-frame-*` CSS로 실제 화면에도 연결했습니다. 이
문서를 다시 수정하고 싶으면(티어 재배정 등) 아래 표를 고친 다음 schema.sql 섹션 27의 `update
shop_items set tier = ...` 값 목록을 같이 갱신해야 합니다 — 이 문서는 더 이상 "코드에 반영되지 않은
초안"이 아니라 실제 스키마 값의 근거 문서입니다.

## 기준

`supabase/schema.sql`의 `grant_title()` 호출 지점을 전부 찾아서 각 칭호의 실제 획득 조건(횟수
누적, 특정 시간대, 특정 상황 등)을 확인하고, 아래 기준으로 6단계에 배치했습니다:

- **브론즈**: 1회성/자동 획득, 또는 우연히 걸리는 조건 (예: 특정 시간대에 완료하면 그냥 됨)
- **실버**: 가벼운 반복(5~10회) 또는 가입 직후 자연스럽게 달성되는 것
- **골드**: 중간 반복(20~50회) 또는 약간의 의식적 노력이 필요한 조건
- **플래티넘**: 큰 반복(100회+) 또는 꽤 오랜 기간의 꾸준함이 필요한 조건
- **다이아**: 매우 큰 반복(200~300회+) 또는 특별한 상황이 여러 번 겹쳐야 하는 조건
- **마스터**: 각 카테고리에서 사실상 가장 높은 상한선 (최상위 단 하나씩만 배치)

카테고리별 개수는 일부러 맞추지 않았습니다 — 실제 조건 난이도를 그대로 반영한 결과라, 카테고리마다
다이아/마스터가 없는 곳도 있습니다(아래 표에 왜 없는지 짧게 적어뒀습니다).

**전체 분포(참고용)**: 브론즈 16 / 실버 23 / 골드 22 / 플래티넘 8 / 다이아 4 / 마스터 3 (총 76) —
아래로 갈수록 좁아지는 피라미드 모양이라 "희귀한 건 마스터" 방향과 맞습니다.

## 수정하는 법

이 표에서 "제안 티어" 칸만 고치면 됩니다. 다 검토하시고 나서 저한테 "이 문서대로 반영해줘" 라고
하시면, `shop_items`에 `tier` 컬럼을 추가하고 이 표대로 값을 채우는 스키마 작업을 진행할게요.
