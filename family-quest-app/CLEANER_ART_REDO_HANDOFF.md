# 집안일 클리커 — 아트 재작업 인수인계 문서 v6 (GPT/이미지 생성 도구용)

**이번 라운드는 2단계 게이트 방식입니다.** 1차로 딱 3장만 먼저 받아서 검수하고,
그게 통과해야만 2차(전체 프레임/배경)로 넘어갑니다. **1차가 승인되기 전까지는
나머지 프레임이나 배경을 만들지 마세요.**

## 0. 지금 상태 (범위 확정)

**그대로 유지 (건드리지 않음)**:
- 게임 기능/UI 코드 전체
- `items-v9` (도구 아이콘 9종 — 이미 통과해서 실제 앱에 배포됨)
- `items-motion-v10` (작동 중 도구 아이콘 5종 — 이미 통과해서 배포됨)
- 지금 배치/이동 경로/피버/업그레이드/업적 관련 기능 전부

**폐기하고 새로 제작**:
- `actor-v8`, `actor-v11` (캐릭터) — 실패, 재작업
- `clutter-v4` (오염물) — 실패, 재작업
- `backgrounds-time-v3` (배경) — 실패, 재작업

**중요한 제약**: 기존 고해상도 이미지를 색상 축소/포스터라이즈/픽셀화 필터로
변환하는 방식은 금지입니다. 이미 두 번 시도했고 두 번 다 실패했습니다 (그라디언트
경계가 얼룩으로 남거나 팔레트가 깨짐). **저해상도 논리 캔버스에서 처음부터 실제
도트그래픽으로 새로 그려야 합니다.**

## 1. 1차 검수용 — 딱 3장만

| # | 파일 | 내용 |
|---|---|---|
| 1 | 캐릭터 기본 대기 프레임 1장 | 정면 서 있는 기본 포즈 |
| 2 | 거실 오전 배경 1장 | living room, morning |
| 3 | 장난감 오염물 1장 | toy clutter |

### 1차 기술 스펙

| 항목 | 캐릭터 | 오염물 | 배경 |
|---|---|---|---|
| 논리 캔버스 | 128×128 | 128×128 | 256×256 (또는 그와 비슷한 실제 저해상도) |
| 배경 | 투명 PNG | 투명 PNG | — |
| 팔레트 상한 | 40색 | 40색 | 96색 |

공통 규칙:
- 알파는 **0 또는 255만** (반투명 경계 금지)
- 안티앨리어싱, 그라데이션, 블러, 디더링 금지
- 굵고 일정한 픽셀 외곽선
- **좌측 상단 광원 + 3톤 셀 셰이딩** (밝은 톤 / 중간 톤 / 그림자 톤, 그 이상 금지)
- **`items-v9`와 같은 픽셀 밀도·색 처리** (이미 통과한 그 스타일 그대로)
- 캐릭터의 얼굴, 눈 색, 머리 모양, 비율, 빨간 작업복은 **유지** (다른 캐릭터처럼 보이면
  안 됨)
- **머리카락의 빨간 얼룩은 완전히 제거** (지난 두 번의 실패 원인)
- 새로운 장식이나 얼굴 요소를 임의로 추가하지 말 것

### 1차 결과 제출 형식

파일 3장과 함께, **각 파일의 해상도 / 불투명 색상 수 / 알파 값 종류(0·255만 있는지)를
표로 정리해서 같이 제출**해주세요. 이 표 + 실물 3장을 같이 검수한 뒤 통과 여부를
알려드립니다.

## 2. 2차 (1차 통과 후에만 진행)

1차가 승인된 뒤에만 아래를 진행합니다:

- **`actor-v12`**: 대기·빗자루·걸레·장갑 각 8프레임 (총 32장)
- **`clutter-v5`**: 먼지·종이·얼룩·장난감 4종
- **`backgrounds-time-v4`**: 거실·주방·욕실·아이방 × 오전·오후·저녁·밤 = 16장

**기존 폴더(`actor-v8`, `actor-v11`, `clutter-v4`, `backgrounds-time-v3`)를
덮어쓰지 말고, 위의 새 폴더명을 그대로 사용하세요.**

### 캐릭터 프레임 일관성 규칙

- **한 장의 고정 마스터 베이스에서 모든 프레임을 파생**시킬 것. 프레임마다 머리 크기,
  얼굴, 손, 발, 몸통, 의상 색, 중심축이 바뀌면 안 됩니다.
- **대기 모션**: 입은 닫힌 상태 유지, 발은 고정. 전신의 아주 작은 호흡과 자연스러운
  눈 깜빡임만 표현합니다.
  - 금지: 입을 벌리는 호흡, 머리만 움직이는 동작, 몸 전체가 위로 뜨는 동작
- **빗자루질/걸레질 모션도 대기 상태와 화면상 캐릭터 크기·발 기준선이 동일**해야
  합니다. 도구 모양이나 손 위치가 프레임마다 어긋나면 안 됩니다.

### 2차 최종 제출 형식

전체 제작 후, **소스 경로를 실제로 교체하기 전에** 모든 파일에 대해 다음을
자동 검사한 보고서를 먼저 제출하세요:
- 해상도
- 색상 수
- 알파 값 종류
- 바운딩 박스
- 프레임 간 중복 여부

이 보고서 + 실물을 먼저 검수한 뒤에만 실제 소스 경로 교체를 진행합니다.
