# 기능 총정리 (한눈에 보기, 2026-08 기준)

지금까지 여러 문서(`README.md`/`CORE_APP_DESIGN.md`/`GAMIFICATION_DESIGN.md`/
`MONETIZATION_DESIGN.md`)에 나뉘어 있던 내용을 한 곳에 모은 요약 문서입니다. **각 항목의
자세한 설계 근거는 저 문서들에 있고, 여기는 "지금 뭐가 되어 있는지"를 훑어보기 위한
용도**입니다. 이 문서 자체가 자동으로 최신화되지는 않으니, 큰 기능이 추가/제거되면 이
문서도 같이 손봐주는 게 좋습니다.

**상태 표시 기준**:
- ✅ 라이브 — 지금 앱 켜면 바로 씀
- 💤 구현 완료, 현재 비활성 — 코드/DB는 다 있는데 UI에서 꺼둔 상태
- 🚧 코드는 완료, 설정값 대기 — 외부 계정 연결해야 실제로 동작
- 📋 설계만, 착수 전

---

## 1. 개요

- React 19 + TypeScript + Vite 8 + Supabase(Postgres/Auth/Storage/Realtime/Edge
  Functions), PWA. `family-quest-app`이 원본 소스이고 `business-quest-app`(컴퍼니퀘스트)이
  같은 소스 트리를 `@core` alias로 그대로 가져다 쓰는 별도 앱(브랜딩/일부 문구만 다름).
- 방 종류 3가지: **개인방**(혼자 쓰는 할 일 관리, 의뢰금 없이 무료) / **가족방** / **회사방**
  (CSV 리포트 가능). 한 계정으로 여러 방에 동시 소속 가능.

## 2. 계정 / 인증 ✅

- 이메일/비밀번호 회원가입·로그인, 비밀번호 재설정
- **생일 필수 입력** (family-quest-app만, 회원가입 시) — 미성년자 이용자가 실제로 있어서,
  나중에 광고 개인화 여부를 나이 기준으로 태깅하기 위한 사전 준비. 기존 가입자는 앱 진입 시
  한 번 채우게 막는 게이트 화면(`BirthdayRequiredScreen`)이 대신 처리
- **회원 탈퇴** — 신청 시 7일 유예기간(그 안에 취소 가능), 지나면 로그인 영구 차단 +
  개인정보 익명화. 다른 멤버가 남아있는 방의 방장이면 탈퇴 신청 자체가 막힘
- 기기 언어 자동 감지(한국어/일본어) + 수동 전환, 선택 언어는 프로필에 저장

## 3. 방 (가족방/개인방/회사방) ✅

- 생성 시 8자리 초대 코드 자동 발급 (QR 코드로도 공유 가능), 참여자 인원 제한 없음
- 방 이름 변경, 초대 코드 재발급, 멤버 내보내기, 방 나가기
- 방장이 다른 멤버가 있는 방을 나가면 자동으로 방장 위임
- **방 생성 슬롯**: family-quest-app은 기본 1개, 광고 제거를 산 방마다 +1개씩 순차 해금 (🚧
  실제 결제 연결 전까지는 항상 1개 고정, 아래 15번 참고). 회사방(business-quest-app)은 이
  제한과 무관

## 4. 퀘스트 (핵심 루프) ✅

- 등록 → 담당자 지정 → 완료 처리 → 필요 시 재오픈
- **배정 방식 3종**, 담당자 수만으로 자동 판별: 특정인 지정 / 모두(협업, N분의 1 지급) /
  선착순(경쟁, 전액 독식)
- 공유 방(2인 이상)에서는 등록 시 포인트를 걸고(최소 5포인트), 완료 시 완료자가 수령 +
  의뢰자에게 소액(10%) 환급 보너스. 자기어뷰징 방지 로직 있음 (본인이 본인에게 배정하고
  본인이 완료하면 포인트/명성 둘 다 0)
- 시작일 지정 가능(시작 전엔 "예정" 상태), 반복(매일/매주 요일 지정/매월)
- 기한 초과 시 자동 유찰(실패 처리) + 걸었던 포인트 환급, 다음 회차 자동 생성(반복 퀘스트)
- 완료 2단계 플로우: 완료 보고 → 등록자 승인/반려 (본인이 등록+본인이 완료면 이 단계 생략)
- 댓글, 자주 쓰는 의뢰 템플릿(담당자 포함 저장), 검색/필터(진행중·완료·전체)/일괄
  선택-완료·삭제/핀 고정/실행취소
- 캘린더 뷰, 완료 사진 모아보기(사진첩)

## 5. 채팅 ✅

- 가족방 단위 채팅, 파일 첨부 (사진뿐 아니라 전체 파일 타입, 건당 8MB)

## 6. 알림 ✅

- 인앱 알림 벨 (읽음 처리, 안 읽은 개수 배지)
- 기기 푸시: 마감 임박 / 담당 배정 / 완료 / 댓글 / 마감 초과(에스컬레이션) / 주간 요약 —
  종류별로 켜고 끌 수 있음
- 앱 아이콘 배지 (내 담당 진행중 퀘스트 개수, 지원 브라우저만)
- **전송 채널**: 지금까지는 브라우저 표준 Web Push였는데, **안드로이드 WebView는 이 방식을
  지원하지 않는다는 걸 확인**해서 FCM(Firebase Cloud Messaging) 경로를 별도로 추가함 (🚧
  코드 완료, Firebase 프로젝트 설정 전까지는 PWA/웹 설치 사용자에게만 실제로 감)

## 7. 게임화

### 7-1. 항상 라이브 ✅
- 포인트(소비 가능, 방별 잔액) / 경험치(레벨용, 계속 누적) 분리 체계
- 레벨이 오를수록 필요 경험치가 늘어나는 성장형 레벨, 대시보드 상단에 레벨/경험치 진행바
- 연속 완료 스트릭, 완료 시 컨페티 애니메이션 + 랜덤 축하 메시지
- 뱃지(조건 달성형) + **칭호 약 80여 종** (테마별 탭으로 구분, 절반 정도 도달 시 "잠긴 칭호"
  미리보기 노출, 완전 히든 칭호도 존재) — 내 통계 화면(`MyStatsModal`)에서 갤러리로 확인
- 주간 리포트: 가족별 이번 주 완료 현황 + MVP 하이라이트 (인앱 + 매주 월요일 푸시)

### 7-2. 구현 완료, 현재 비활성 💤
`src/lib/featureFlags.ts`에서 끄고 켤 수 있음 — 로직/DB/RPC는 전부 살아있고, **비주얼
아트 방향이 아직 안 정해져서** UI 진입점만 잠깐 숨겨둔 상태 (플래그만 다시 켜면 바로 복귀):
- **캐릭터 커스터마이징** (`CHARACTER_CUSTOMIZATION_ENABLED`) — 포인트로 캐릭터 꾸미기
  (피부/배경/상의/하의/신발/머리/무기/방패/장신구 2종, 11개 슬롯). 아바타 자체(정체성
  표시)는 계속 보이고, 눌러서 상점 여는 동작만 막혀 있음
- **청소 미니게임** (`GAME_FEATURES_ENABLED`) — 방치형 클리커(옛 "타이쿤" 시스템을
  대체한 것). 대시보드의 🧹 아이콘 진입 버튼이 꺼져 있고, 이 게임 전용 뱃지/칭호도 갤러리
  목록에서 자연스럽게 제외됨(이미 딴 사람 것만 예외로 계속 보임)

### 7-3. 회사방 커스터마이징 📋
회사방마다 게임화 요소를 세분화해서 켜고 끄는 기능 — 방향만 잡혀 있고 미착수
(`GAMIFICATION_DESIGN.md` 9번)

## 8. 개인화 / 설정 ✅

- 라이트/다크 모드 + 5가지 색상 테마(퍼플/핑크/블루/그린/오렌지)
- 프로필 사진 업로드(드래그/줌 크롭), 방별 표시 이름 오버라이드, 상태 메시지
- 튜토리얼(최초 1회 자동 실행 + 설정에서 다시보기)
- 문의하기(mailto), 이용약관·개인정보처리방침 링크

## 9. PWA ✅

- 홈 화면 설치 가능 (Android Chrome / iPhone Safari 16.4+)
- 마지막으로 보던 화면 기억 (백그라운드 재시작 시 복귀)
- 오프라인 모드는 없음 (앱 셸만 프리캐시, API 호출은 항상 네트워크)

## 10. 법적 / 신뢰 ✅

- 개인정보처리방침 (한국어/일본어 별도 작성 — 한국은 PIPA, 일본은 APPI 기준으로 구조 자체가
  다름), 이용약관
- Row Level Security로 방 데이터 완전 분리 (다른 방 데이터는 애초에 쿼리 자체가 안 됨)

## 11. 컴퍼니퀘스트 (business-quest-app, 별도 배포) ✅

- family-quest-app과 동일 코드베이스, `room_type='business'` 고정 온보딩 + 문구만 다름
  (`businessOverrides.ts`)
- **CSV 리포트**: 회사방에서만 주간 리포트 모달에 CSV 다운로드 버튼 노출 (완료 퀘스트
  제목/담당자/완료일시, 엑셀 한글 깨짐 방지 UTF-8 BOM)
- 생일 필수 입력/광고 관련 기능은 대상 아님 (B2B 앱, 아래 12번 참고)

## 12. 수익화

### 12-1. 패밀리퀘스트 — 광고 기반 무료 🚧
`MONETIZATION_DESIGN.md` 1번. **코드는 전부 작성 완료**, Google Play Console/AdMob/
RevenueCat 계정 3개 설정 전까지는 비활성:
- 광고 제거 방 단위 1회성 구매(~300엔) — 사면 그 방 멤버 전원 광고 없음
- 방 생성 슬롯이 광고 제거할 때마다 +1개씩 순차 해금
- 미성년자 이용자 대응: 회원가입 생일 필수화 → 나이 기준으로 광고 개인화 여부 태깅 (지금은
  안전하게 전원 비개인화 광고로 요청)

### 12-2. 컴퍼니퀘스트 — B2B 구독 📋
`MONETIZATION_DESIGN.md` 2번. 방향만 정해짐, 코드 착수 전:
- 스토어 미판매, B2B 직판 (Stripe/Komoju 등), 1개월 무료체험
- Standard(~50명)/Pro(~300명)/Premium(~1000명), 플랜 오를수록 인당 단가도 오르는 구조
- 사원 관리(출퇴근 등)는 완전 별도 프로젝트로 분리 예정

## 13. 앱스토어 출시 준비 상태

- Capacitor로 안드로이드 네이티브 앱 스캐폴드 완료 (`android/` 디렉터리)
- AdMob(광고)/RevenueCat(결제)/FCM(푸시) 연동 코드 전부 작성 완료, **외부 계정 3개 + 실기기
  테스트만 남음** (`README.md` "3-2"/"3-3" 참고)
- **아직 스토어 등록 안 함** — 실기기 화면 검증이 한 번도 없었기 때문에 의도적으로 보류 중
  (사용자 판단)

## 14. 자동화 테스트

- `npm test` (vitest) — 레벨/경험치 곡선 공식, 칭호 카테고리 분류 로직 등 7개 케이스
- 그 외 검증은 `npm run build`(tsc -b + vite build, 타입/빌드 오류 검출용 필수 명령)와
  `npx oxlint src/`
